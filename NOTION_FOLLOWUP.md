# Notion follow-up handoff

Notion migration is intentionally excluded from the first Docusaurus rebuild.

## Why it is deferred

- The workspace mixes technical notes with life admin, work logs, journals, and unsorted excerpts.
- Some pages contain private or sensitive information that must never be published.
- Content curation is a separate problem from rebuilding the public site.

## Suggested next change

`curate-and-migrate-notion-knowledge-base`

## Suggested workstream

1. Inventory technical pages separately from personal and work material.
2. Isolate sensitive pages before any migration work.
3. Classify candidate notes into:
   - publish as docs
   - rewrite as blog
   - keep private
   - discard/archive
4. Delegate batch triage to another agent only after the classification rubric is stable.
